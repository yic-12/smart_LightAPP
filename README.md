# 智能照明系统 (Smart Light APP)

基于HarmonyOS的智能照明控制系统

## 项目简介

本项目是一个基于HarmonyOS开发的智能照明控制应用，使用ArkTS语言开发，实现了对智能灯光设备的全面控制功能。

## 功能特性

- **灯光开关控制**：一键开启/关闭灯光
- **亮度调节**：支持0-100%无级调光
- **色温调节**：支持2700K-6500K色温调节（暖光-冷光）
- **设备管理**：支持多个照明设备的管理
- **直观UI界面**：简洁美观的用户界面设计

## 技术架构

### 开发环境
- **开发语言**：ArkTS (TypeScript based)
- **开发框架**：HarmonyOS SDK API 9
- **开发工具**：DevEco Studio
- **UI框架**：ArkUI声明式开发范式

## 核心功能说明

### 1. 数据模型 (LightModel.ts)

- **LightDevice 类**：表示单个照明设备
  - 属性：ID、名称、开关状态、亮度、色温
  - 方法：开关切换、亮度设置、色温设置

- **LightingManager 类**：照明系统管理器（单例模式）
  - 设备初始化
  - 设备管理（添加、获取、列表）

### 2. 用户界面 (Index.ets)

- **标题栏**：显示应用名称
- **灯光状态卡片**：
  - 灯泡图标显示
  - 设备名称
  - 当前状态（开启/关闭）
  - 开关按钮
- **亮度控制区域**：
  - 滑动条调节亮度
  - 实时显示百分比
- **色温控制区域**：
  - 滑动条调节色温
  - 暖光到冷光范围指示

### 3. 应用能力 (EntryAbility.ts)

- 应用生命周期管理
- 页面加载和导航
- 日志记录

## 使用说明

### 开发环境配置

1. 安装 DevEco Studio 3.1 或更高版本
2. 配置 HarmonyOS SDK（API 9）
3. 克隆本项目到本地

### 运行项目

1. 使用 DevEco Studio 打开项目
2. 连接 HarmonyOS 设备或启动模拟器
3. 点击运行按钮进行编译和安装

### 操作指南

1. **开启/关闭灯光**：点击主界面中央的开关按钮
2. **调节亮度**：拖动亮度滑块，范围0-100%
3. **调节色温**：拖动色温滑块，从暖光(2700K)到冷光(6500K)

1. **声明式UI开发**：使用ArkTS声明式语法，代码简洁清晰
2. **响应式状态管理**：@State装饰器实现UI自动更新
3. **组件化设计**：代码模块化，便于维护和扩展
4. **单例模式**：设备管理器采用单例，保证数据一致性
